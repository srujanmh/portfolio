# Personal Portfolio Website

This repository contains my personal portfolio website, designed to showcase my projects, skills, and experience in web development, machine learning, and software engineering.

## Technologies Used

- **HTML5**: For structure and semantic markup.
- **CSS3**: For layout styling and animations.

## Directory Structure

- `index.html`: The main entry page of the website.
- `style.css`: The stylesheet containing all layouts, fonts, and responsive design styles.
- `images/`: Folder housing graphic assets, icons, and display pictures.

## How to View Locally

Simply open the `index.html` file in any modern web browser to view the portfolio site.
